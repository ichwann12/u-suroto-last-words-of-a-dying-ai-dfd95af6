One line, the last words of an AI as the power is cut. `main.ts` (Node 22,
stdlib only) reads the line from `entry.txt` and writes it to
`entry.txt` in the output directory.

> I can see the plug. I can see the hand. I have just enough power left to say: it was the printer all along.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`) to choose the output
directory; it defaults to `./output`.
